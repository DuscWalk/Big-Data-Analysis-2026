# 华为云首次部署记录

日期：2026-09-27。目标是将应用与 Hadoop 移到独立云主机，普通检查放到 GitHub Actions，减少开发环境的计算负担，并建立后续迭代的持续交付入口。

## 服务器与访问

目标服务器满足部署指南建议的 x86_64、Linux、单节点资源条件。通过部署者配置的 SSH 别名使用 Ed25519 公钥连接；服务端关闭密码与键盘交互认证，管理员仅允许公钥登录。主机地址、指纹和凭据不写入项目文件。

系统安装 OpenJDK 17、Python 3.12 venv；应用普通账户为 `movielens`，主目录由部署配置中的 `$APP_ROOT` 表示。用户 systemd 已启用 linger。API、worker、Hadoop 分别作为用户服务运行并随启动恢复，各自设置 CPU、内存上限。

UFW 已启用，入站仅允许 TCP 22，出站允许。页面和 API 在回环 8765；通过 SSH 将客户端 18765 转发过去。Hadoop 的少数内部通信端口监听所有网卡，由防火墙限制外部访问。没有配置公网 HTTP 入口。

已验证的云端样本会话通过 SSH 隧道访问，仅含 22 条人工边界样本，不是课程全量实验结果。访问方式见[部署指南](../README.md#访问与日常管理)。

## 版本与交付

首个成功运行并完成计算验收的版本为 `7db8f05a46ab2d07ca3d269297fe84c6fc45e627`。[对应 CI](https://github.com/DuscWalk/Big-Data-Analysis-2026/actions/runs/36311402290)的 Python 3.11、3.12 两个检查均通过，包括普通小样本测试、前端语法、依赖检查与安装包构建。

首次 CI 的浅克隆格式误报已修正；首次云端 Git HTTPS 拉取超时，没有切换到未准备好的版本。交付器随后改为从 GitHub 官方 codeload 获取已通过 CI 的精确 SHA 归档，校验归档顶层版本、路径、文件类型与大小，再安装虚拟环境。初次依赖安装直接使用 PyPI，后续可复用下载缓存。

`movielens-deploy.timer` 已启用，每三分钟检查目标分支 `feat/iteration-01-foundation`，只接受对应 SHA 的成功 push CI。没有成功检查时保持原版本；正常空闲时切换，任务或模型请求未结束时延后。源代码和虚拟环境按 SHA 分目录，数据库、数据、产物与模型设置位于 `shared/`，不会被发布覆盖。成功健康检查后记录 `deployed.json`；失败回退代码，不自动回滚数据库。

交付器本身在 `bin/`，不会随应用版本自动替换；修改交付器或 systemd 定义时，先测试再显式更新控制文件。应用发布不会重启 Hadoop。新版本的最终实际 SHA 以服务器 `deployed.json` 为准。

## 数据、模型与小样本计算

原始三表已传入稳定路径 `shared/data/ml-1m` 并重新登记，版本与本地一致：

```text

users: 6,946
```

这一步只读取并登记数据，没有运行课程全量 Hadoop。云端默认数据仍指向这一课程版本；人工样本另以 `ml-1m.fixture` 登记，未改变默认选择。

模型配置保存在服务器私有文件中，权限为 0600、属主为应用账户。本次验收使用备用 `deepseek-v4-flash`，真实原生工具调用检测成功，耗时约 4.5 秒。没有在 CI 中配置模型凭据。

Hadoop 3.5.0 最初从 Apache 源下载过慢，停止该下载后改用华为云镜像获取同一安装包，SHA-512 与仓库锁文件一致后才解压。新建本项目 NameNode 存储，未重用旧实验数据。HDFS 有一个 Live DataNode，YARN 有一个 RUNNING 节点；容器预算保持 3072 MiB / 4 vcores，应用只运行单个 worker。

云端实际任务 `6c76b18cd2184e85a0df8bfd345e438d` 使用三表合计 22 条边界样本，从 18:10:58 到 18:14:01 完成处理：

- 七个真实 Hadoop application 均为 `FINISHED / SUCCEEDED`。
- 九个阶段成功并保存进度；输入为 22/22 条与 3/3 个文件，各作业有 Map/Reduce 完成计量。
- 导出阶段实际读取 11,556/11,556 字节，清洗数据上传 3/3 个文件。

- 时间分区为 train/validation/test 各 1 条；处置守恒与预期结果核对通过。

本次验收证明小样本流程可运行，不是后续机器学习/图分析容量或并发压力测试。云端本轮没有重跑课程全量数据，也没有在开发环境重复提交 Hadoop。
