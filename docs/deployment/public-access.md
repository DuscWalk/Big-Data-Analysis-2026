# 公网 HTTPS 访问

工作台可以由 HTTPS 反向代理提供公网入口，API 继续监听回环地址。入口覆盖页面、所有 API、模型设置、历史会话和下载，统一要求访问密码。应用仍是小组共享工作台，入口密码不提供成员之间的会话隔离。

## 入口配置

[nginx 模板](../../deploy/nginx/movielens.conf.template)可用于独立域名或公网 IP 加独立 HTTPS 端口。替换以下占位项后安装成独立站点，避免覆盖服务器上的其他服务：

| 占位项 | 含义 |
| --- | --- |
| `__PUBLIC_HOST__` | 域名或公网 IP，仅主机部分 |
| `__HTTPS_PORT__` | HTTPS 监听端口；独立域名通常为 443，共用 IP 可采用空闲独立端口 |
| `__CERTIFICATE_FILE__`、`__CERTIFICATE_KEY_FILE__` | 实际证书链和私钥路径；证书须覆盖上述域名或 IP |
| `__PASSWORD_FILE__` | nginx 可读的 htpasswd 密码摘要文件，禁止写进仓库 |

填写服务器共享 `.env`：

```dotenv
PUBLIC_ORIGIN=https://your-domain.example:8443
```

此项是精确 HTTPS 来源，不带路径或末尾斜杠；省略标准 443 端口即可。应用按该主机启用访问白名单，写请求的 `Origin` 必须与实际请求的协议、主机和端口一致。代理必须保留 `Host` 和 `Origin`，并由自身设置 `X-Forwarded-Proto`；不能通过清空 Origin 或任意放行 Host 绕过校验。原回环访问与 SSH 隧道仍可用。

页面模型设置不会覆盖 `PUBLIC_ORIGIN`。变更后需在无任务和回答运行时重启 API；后续 CD 继续读取共享 `.env`。该配置本身不提供认证，必须与入口密码一起部署，API 不应直接对公网监听。

## 安装与维护

1. 确認服务域名或 IP、监听端口与有效证书。若同一主机已有匹配的证书，可复用，并确认其自动续期会重新加载 nginx。IP 短期证书尤其需要有效的续期定时器；不要使用自签名证书作为正常访问入口。
2. 用 `htpasswd` 交互建立密码文件，或将随机密码经 `openssl passwd -6 -stdin` 转成密码摘要。只有入口代理需要读取摘要；不要在命令参数、日志或 Git 中保存明文密码。
3. 设置共享 `.env` 的 `PUBLIC_ORIGIN`，确认运行代码包含此配置支持。安装渲染后的独立 nginx 站点，执行 `nginx -t`，通过后 reload；保留其他站点及其证书续期配置。
4. 在主机防火墙和云安全组仅开放选择的 HTTPS 入口。既有 HTTP 端口可承担证书验证；不开放应用回环端口或 Hadoop 管理、计算端口。
5. 从外部网络检查证书有效、匿名访问和错误密码返回 401、正确密码能打开工作台、同源写请求可用、跨源写请求被拒绝、历史报告可读，以及手机布局正常。

账号和密码通过本地私有文件交付给负责人，由负责人分发。可用同一个密码文件增加成员独立用户名，后续可单独修改或撤销；当前仍共享模型设置、治理默认和历史记录。浏览器弹出的登录框来自 nginx，部分浏览器会缓存凭据，不能把关闭页面等同于退出登录。

控制文件不属于应用自动发布：nginx 站点、入口密码、证书、续期任务和防火墙由服务器管理员维护。应用的 `main` → CI → CD 流程保持不变。证书私钥与模型密钥不进入源码或构建包。

## 验证范围

本次代码检查覆盖公网主机显式启用、合法 HTTPS 来源、错误协议/端口/外部 Origin 拒绝，以及保留本地隧道。公网入口的匿名拒绝、正确密码、浏览器和证书需在服务器安装后实测，不能用单元测试代替。
