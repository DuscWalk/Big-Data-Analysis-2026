# 交接后的成员操作与演示检查

负责人完成的工程验收与数据搬迁见[收尾记录](../reports/2026-09-27-收尾验收.md)，接手入口见[交接说明](交接说明.md)。本页用于记录成员自行操作及真人演练，不以未填写的个人记录阻塞已完成的代码收尾。

代码使用 `main`，固定基线为 `iteration-01-v1.0`。以下待办没有因为文档存在而自动通过。

## 成员开始开发时

- [ ] 确认自己的 GitHub 协作者权限、Git 作者身份；从最新 `main` 创建功能分支。
- [ ] 按[环境指南](../../../development/environment.md)准备 Python 环境，运行普通小样本检查。
- [ ] 取得[完整交接包](交接说明.md)，核对摘要和固定引用，按[读取指南](清洗数据读取.md)读取需要的时间分区；记录自己的环境和结果。
- [ ] 阅读[工具扩展入口](../../../development/tasks-and-tools.md)，确定自己算法的输入、输出和公共接口变化。
- [ ] 需要云端页面时提供个人 SSH 公钥并配置别名。计算验收提前协调；日常开发无需启动本地 Hadoop。
- [ ] 汇总下一轮接口疑问，以及 HW2/HW3 可用的问题证据和技术选择理由。

仅消费交接数据不需要模型或 Hadoop。课程数据、课件、`.env`、运行目录和成员密钥不随 Git 同步；服务器端口转发账号也不自动获得数据目录的读取权限。
