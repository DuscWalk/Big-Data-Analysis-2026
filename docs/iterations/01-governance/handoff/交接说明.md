## 2. 取得代码、数据和云端入口

代码克隆后使用 `main`，需要固定版本则检出 `iteration-01-v1.0`。Python 使用项目环境，普通 CI 已覆盖 3.11/3.12；[环境指南](../../../development/environment.md)提供安装方式。日常开发和数据读取不需要启动 Hadoop。

完整数据包位于：

```text
$APP_ROOT/shared/handoff/
├── iteration-01-handoff.tar.gz
├── package.json
└── iteration-01/
    ├── dataset-reference.json
    ├── dataset-manifest.json
    ├── users.jsonl
    ├── movies.jsonl
    ├── ratings.jsonl
    ├── quality.json
    └── report.md
```

压缩包为 18,456,977 字节，SHA-256 为 `27eb003327d6cf385bfd7117be22f8d9f128bebde5b71ba8a940902425a44811`。解压后三表约 255 MB。由具备服务器读取权限的交付者获取；示例中的 SSH 别名和应用根目录需按[部署指南](../../../deployment/README.md)替换为实际配置：

```bash
mkdir -p var/handoff
CLOUD_HOST=your-ssh-alias
APP_ROOT=/opt/movielens
scp "$CLOUD_HOST:$APP_ROOT/shared/handoff/iteration-01-handoff.tar.gz" var/handoff/
sha256sum var/handoff/iteration-01-handoff.tar.gz
tar -xzf var/handoff/iteration-01-handoff.tar.gz -C var/handoff
```

核对上述压缩包摘要后，再按[读取指南](清洗数据读取.md)核对产物引用和各文件摘要。数据包没有完整处置明细 `dispositions.jsonl`，该大文件仍保存在生产任务目录；报告内已有代表性样例，需要逐条审计时由负责人提供原文件。原始数据、模型密钥和旧 SQLite 没有打包。

另外两人尚未配置服务器 SSH 访问。只浏览页面可开独立 SSH 端口转发账号；需要取数据时由负责人交付上述包，或明确配置只读文件权限。仅有隧道权限不等于具有服务器文件读取或命令执行权限。GitHub 协作者权限已经具备，SSH 接入按需提供各自公钥；没有共享负责人的私钥或 root 身份。

已配置账号的成员可按[部署指南](../../../deployment/README.md)建立本地 18765 → 云端 8765 隧道，再访问云端页面。`CLOUD_HOST` 是各自电脑配置的 SSH 别名，需各自设置。

## 3. 下一轮如何接入

1. 从 `origin/main` 建立自己的功能分支，例如 `feat/iteration-02-tools`。修改后提交 PR，由另一人评审；合并提交通过 CI 后才更新共享环境，详见[Git 工作流](../../../development/git-workflow.md)。
2. 用 `CleanedDataset` 读取固定清洗版本。用户/电影/评分为 5,895 / 3,836 / 935,354 行；train/validation/test 为 746,139 / 100,814 / 88,401。分区按时间过滤，没有独立分区文件。
3. 迭代二分类标签为 `rating >= 4`；画像、标准化、聚类和降维变换只用训练期拟合。数据版本、split 引用、参数、训练截止时间和实际评价分区进入新产物。
4. 输入输出定义在 `contracts.py` 或相应业务契约中，工具通过 `tools/registry.py` 注册。每种算法是独立工具；长任务使用 `TaskStore.submit`，新增工作流由 `jobs/worker.py` 的 handler 字典分发。
5. 新工作流准备并校验文件，沿用任务进度、外部作业 ID 和原子发布；新增产物类型和页面视图同步补充接口文档。改动公共协议时，请另一轮负责人参与评审。
6. 迭代三记录图谱来源、训练截止时间及图谱/投影版本；先完成图谱校验，再运行推荐、图挖掘和链接分析。具体算法要求以课程文档为准。

可运行的注册示例为 [catalog_versions.py](../../../../scripts/examples/catalog_versions.py)，数据读取示例为 [read_cleaned.py](../../../../scripts/examples/read_cleaned.py)。共享运行目录由发布器管理，成员在自己的分支开发。
