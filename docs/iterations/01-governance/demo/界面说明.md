## 页面内容

- **本次实验**：清洗后评分、隔离评分与已发布文件数量，全部来自当前任务。下方保留任务选择、状态、执行阶段和刷新。
- **五维质量**：逐项显示清洗前值、清洗后值、分数差与 0—100 的条形图；不合成总评分。满分与真实性的边界仍明确说明。
- **数据处置**：三表输入、输出、修复、去重与隔离；时间划分以实际行数显示比例，标明未另存分区文件。
- **产物与证据**：文件名称、大小与下载；清洗样例、异常来源和版本继续可查。
- **实验助手**：从最新回答开头阅读，保留历史、调用依据和失败重试；正在发送时有状态反馈，报告仍可操作。
- **治理配置**：页头打开清洗开关、时效参照/窗口、三表权重与 T1/T2 表单；可保存并选用，或直接一键设为默认。助手旁选择新任务方案，也可用自然语言描述修改；任务面板能展开实际配置快照。具体操作见[应用指南](../../../development/app-and-model.md#清洗规则与评分配置)。

桌面右侧助手随页面滚动保持可用。手机可用底部“查看结果 / 使用助手”跳转，长对话与宽表格在所属区域内滚动。原有 Ctrl / ⌘ + Enter 发送、快捷问题、新建会话继续有效。

调用依据、清洗样例和异常样例支持在原按钮处展开与收起，展开后按钮分别显示“收起调用依据”“收起样例”和“收起依据”。首次展开读取记录，同一内容再次展开使用当前页面缓存；切换数据表、异常规则、任务或刷新结果时清空相应样例与展开状态。加载期间也可以收起，结果返回后保持收起；读取失败后可再次点击重试。执行阶段、评分依据和版本信息使用原生折叠面板，同样支持鼠标和键盘操作。

选中已有任务后仍可正常聊天。发“你好”、询问使用方法或概念时，模型按当前问题回答；问“任务完成了吗”时查询状态，问评分损失或来源样例时才读取报告。“再给一个”可承接同任务的最近一次成功样例。实际报告回答仍标记为“报告事实”，普通模型回答不带报告校验标记。行为与验证见[对话入口实测](../reports/2026-09-27-对话入口与报告取证实测.md)。

模型栏显示配置的模型与服务角色，不表示实时服务健康。无任务或任务未发布时概览显示“—”；新会话及失败状态不会残留上一任务的数字。

## 查看执行阶段

展开“查看执行阶段”后可以看到九个阶段，每个阶段都有进度条与状态。顶部显示“已完成几项 / 共几项”，运行中每 2 秒自动更新，面板保持展开；仍可点击标题收起。当前阶段用朱红边框与状态点提示，系统开启减少动态效果时关闭动画。

- **核对与封装输入**：显示三表累计“已封装条数 / 总条数”和“已上传输入 / 3 个文件”。
- **七个 Hadoop 阶段**：分别显示 Map 和 Reduce 百分比，来自 Hadoop 的实际日志。它们表示两个计算阶段的进度，不是两份数据量；两者到 100% 后可能还需要下载结果，以阶段状态为准。
- **核对并导出产物**：显示“已读取处理结果 / 总大小”和“已上传清洗数据 / 3 个文件”；读取完成后仍会核对行数、外键和文件摘要。

尚未开始的阶段显示等待；正在初始化、还未收到数值的阶段显示等待动画与文字，不随时间编造百分比。失败和“状态待核查”会保留最后数值并停止动画，后续阶段标为未执行；待核查不代表外部作业一定已停止。每个已记录进度的阶段还有最近更新时间。

已有演示任务没有保存处理中的计数，因此显示完成条和“历史任务未记录处理中计数”。新任务才会记录新进度，无需为查看这个面板重新运行全量数据。此次真实进度验证因开发环境资源不足提前停止，剩余检查使用 3 条输入和受控页面响应，范围见[执行阶段进度实测](../reports/2026-09-27-执行阶段进度实测.md)。

## 模型设置与历史会话

首页右上角新增“历史会话”和“模型设置”，助手底部也能进入“配置与检测”。沿用手记版颜色和字体，对话框支持关闭按钮、Esc 和键盘焦点导航，手机在对话框内滚动。

模型设置可编辑主备服务、选择使用方式、调整超时和输出上限。先获取模型列表或直接填写模型 ID，再点击对应服务的“检测连通性”；检测显示本次的结果和耗时。点击“保存设置”后立即对新请求生效，重启后保留。地址和模型名称支持清空保存，重新打开或重启后仍为空；清空任一必需字段后该服务不会参与调用。密钥输入框留空沿用已保存值，勾选清除才删除；关闭面板清空新输入的密钥。重新填写非空地址时需重新提供或明确清除密钥。保存结果显示在按钮旁，失败会明确标注“未保存”。完整规则见[模型指南](../../../development/app-and-model.md)。

历史会话可按标题、用户提问或编号搜索，使用“加载更多”继续浏览；每项显示最近活动、提问摘要、消息数、任务数和当前会话标记。点击后进入原会话与原任务，空会话不残留之前的结果。浏览历史不会自动创建新的解释；需要继续分析时主动发消息。页面内切换会话分别保留输入草稿，刷新后草稿清空。
