## 页面内容

- **本次实验**：清洗后评分、隔离评分与已发布文件数量，全部来自当前任务。下方保留任务选择、状态、执行阶段和刷新。
- **五维质量**：逐项显示清洗前值、清洗后值、分数差与 0—100 的条形图；不合成总评分。满分与真实性的边界仍明确说明。
- **数据处置**：三表输入、输出、修复、去重与隔离；时间划分以实际行数显示比例，标明未另存分区文件。
- **产物与证据**：文件名称、大小与下载；清洗样例、异常来源和版本继续可查。
- **实验助手**：从最新回答开头阅读，保留历史、调用依据和失败重试；正在发送时有状态反馈，报告仍可操作。

桌面右侧助手随页面滚动保持可用。手机可用底部“查看结果 / 使用助手”跳转，长对话与宽表格在所属区域内滚动。原有 Ctrl / ⌘ + Enter 发送、快捷问题、新建会话继续有效。

模型栏显示配置的模型与服务角色，不表示实时服务健康。无任务或任务未发布时概览显示“—”；新会话及失败状态不会残留上一任务的数字。
