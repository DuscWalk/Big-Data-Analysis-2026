# 迭代一演示说明

日常演示使用华为云服务，通过 SSH 隧道访问。当前云端会话是 22 条边界样本的真实 Hadoop 结果；课程全量实验的报告和完整清洗数据另行展示，两者的任务、规模和生产环境分别说明。

## 1. 打开当前云端会话

先按[部署指南](../../../deployment/README.md)设置 `$CLOUD_HOST` 和 `$APP_ROOT`，确认公钥登录可用，再在终端保持隧道：

```bash
ssh -N -L 127.0.0.1:18765:127.0.0.1:8765 "$CLOUD_HOST"
```

已有同端口隧道时直接使用。打开：

- 首页：<http://127.0.0.1:18765/>
- 已验证会话：<http://127.0.0.1:18765/?session=cloud-smoke-20260927>
- 会话标题：`云端验收 · 22 条边界样本`。
- 完成任务：`6c76b18cd2184e85a0df8bfd345e438d`。

应用、worker、Hadoop 已由云端 systemd 管理，关闭隧道不影响计算。其他成员要先配置各自 SSH 账号和别名，访问方式见[部署指南](../../../deployment/README.md)。示例中本地隧道入口为 18765，云端 API 端口为 8765。

## 2. 约 10 分钟展示顺序

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0—2 分钟 | 打开[系统架构](../../../architecture/系统架构详解.md)及指定云端会话 | 模型通过注册工具组织任务，worker 执行 Hadoop，校验产物后发布；公共模块供后两轮复用 |
| 2—4 分钟 | 展开“查看执行阶段”，查看九阶段与七个 application ID，再收起 | 输入 22/22 条、3/3 文件；作业 Map/Reduce 实际进度；导出 11,556/11,556 字节和 3/3 文件。已完成页面展示保存的最终值，不假装正在计算 |
| 4—6 分钟 | 展示五维质量、三表处置、样例和报告下载 | 样本保留用户 2、电影 2、评分 3；评分隔离 8、去重 1。指标的实际值以当前任务报告为准 |
| 6—8 分钟 | 在同一会话发送下方一条追问，展开并收起调用依据 | 答案应引用当前任务；模型响应慢时先讲报告，失败时保留错误并使用报告入口 |
| 8—9 分钟 | 打开[完整数据交接](../handoff/清洗数据读取.md)和[全量报告](../reports/2026-09-24-Hadoop治理实测.md) | 课程完整数据是另一任务：清洗后评分 935,354 条，三分区 746,139 / 100,814 / 88,401；云端只是搬迁验证了这份固定产物 |
| 9—10 分钟 | 展示模型设置、历史会话及[交接说明](../handoff/交接说明.md) | 配置可检测和保存；后续各自分支、PR、CI、云端验收；说明服务波动、unknown 人工核查及共享配置边界 |

可直接复制的追问，逐条发送并等待回答：

```text
请读取当前已完成任务的报告，解释评分记录的输入、保留、去重和隔离数量，并说明这些数量是否守恒。只查询已有结果。
```

```text
四项约束评分满分能证明数据真实无误吗？请结合当前任务的报告简要解释，不要重新清洗。
```

这两句供现场操作，不代表收尾时又执行了一轮模型验收。备用服务已有真实工具调用和追问验证记录；演示当天的连通性与时延需当天检查。

开场可以说：“本轮建立了可复用 Agent 架构和真实 Hadoop 治理流程。这里先用云端的小样本结果展示执行、进度和证据，再介绍提前完成的课程全量结果及其交接数据。”

## 3. 全量结果从哪里看

全量实验的五维评分、处置量和局限见[Hadoop 治理实测](../reports/2026-09-24-Hadoop治理实测.md)及[备用模型全链路实测](../reports/2026-09-25-备用模型全链路实测.md)。云端数据包还包含固定生产任务 `33ce0c793b6e4d92acb6400cd96b3faa` 的 `quality.json` 和 `report.md`，取得方式见[交接说明](../handoff/交接说明.md)。

完整数据包没有导入云端会话目录，不能在上述小样本会话中要求助手解释历史全量任务。需要展示历史全量页面时，查看[本地全量演示参考](本地全量演示参考.md)，先确认原验证环境的 API 和任务记录确实可读；无需为读取历史产物恢复 Hadoop。不同任务的来源标识不得互换。

当前云端默认输入仍是课程完整原始数据。在新会话发送“清洗默认数据”会触发全量计算，不是 22 条样本。例行展示使用已有结果；需要新计算时单独安排窗口并明确输入版本，避免现场重复提交。

## 4. 状态检查与故障处理

通过已配置的 SSH 连接和隧道检查当前运行版本：

```bash
ssh "$CLOUD_HOST" cat "$APP_ROOT/deployed.json"
curl -fsS http://127.0.0.1:18765/api/v1/status
```

服务状态、日志和定时器见[部署指南](../../../deployment/README.md#访问与日常管理)。代码以 `main` 发布，本轮基线为 `iteration-01-v1.0`；任务生产版本继续记录在任务内，不因页面版本更新而改变。

| 现象 | 处理 |
| --- | --- |
| 页面无法访问 | 检查 SSH 隧道和 API 服务；不要重新初始化或格式化 Hadoop |
| 模型超时或返回 502/504 | 保留失败，直接查看已发布报告；需要重试时点击一次“重新解释此问题” |
| 任务为“状态待核查” | 核对 YARN 和阶段日志，不把部分结果当作完成，也不直接连续重跑 |
| 历史任务没有逐阶段计数 | 展示实际完成状态；说明该任务产生时尚未保存这项计量 |
| 等待部署 | 查看 `main` 的 CI 和当前任务；有运行或排队工作时交付器会延后 |

演示当天检查：页面、阶段展开/收起、报告下载、模型连通性，以及一条新追问；记录实际展示的代码和任务。真人 10 分钟演练和课程汇报记录见[检查表](../handoff/复现与演示检查.md)，目前没有代替负责人填写完成。
