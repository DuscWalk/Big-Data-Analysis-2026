# 前端模型设置与历史会话

2026-09-27 开始。用户需要在工作台直接配置模型、检测连通性并进入历史会话。基线为 `ba389ad`，沿用手记版布局与当前主备模型协议。

## 交付范围

1. 模型设置对话框：主服务、备用服务的 API 基础地址、模型名称和密钥；服务选择、超时与输出长度设置。
2. 读取服务提供的模型列表；针对当前表单的某个服务执行一次原生工具调用检测，展示成功/失败、耗时和原因；检测不提交数据任务。
3. 设置保存后对新请求立即生效，进行中的请求沿用开始时的配置。重启仍保留设置。
4. 历史会话列表按最近活动排序，可搜索、分页、查看提问摘要和任务数量，并切换回原会话及其结果。
5. 桌面与手机布局、键盘操作、失败反馈、关闭后重开均可用。

## 实现约定

- `.env` 继续提供启动配置。页面保存的模型配置放在 catalog 同目录的 `*.models.json`，权限为 `0600`，采用临时文件加原子替换；不进入 Git。页面配置优先，命令行探测也读取这份配置。
- 接口不返回已保存密钥，输入框留空表示保留，提供显式清除操作；更换为新的非空服务地址时要求重新填写或清除旧密钥。地址与模型名可清空保存并覆盖启动值，清空地址不自动删除密钥。密钥不写入浏览器持久存储，不显示在验证错误中。
- 保存使用配置修订标识防止旧标签页覆盖新配置。检测可以针对尚未保存的表单执行，并使用已保存密钥补齐未修改项。
- 模型设置独立于治理规则和 Hadoop 工作流；保存时替换应用使用的 Agent 配置实例，不修改正在执行的实例。
- 会话列表只查询已有记录。打开历史、切换任务、手动刷新结果不自动创建解释请求；自然语言请求仍沿用现有执行路径。
- 切换时清空旧结果和调用视图，处理迟到响应；恢复进行中会话的状态，避免旧会话内容进入新会话。

- 后端：配置保留/替换/清除、重启读取、保存失败、修订冲突、密钥不回显、探测与列举模型、运行中请求隔离、会话搜索/分页/范围检查。
- 浏览器：真实接口上的设置保存和重开、主备探测、列表选择、历史切换、桌面/手机/键盘、失败反馈；受控服务用于覆盖失败和并发，真实已配置服务用于一次连通性实测。
