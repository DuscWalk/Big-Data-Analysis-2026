# 迭代一：前端界面优化

状态：已完成，用户选定手记版并用于正式首页。日期：2026-09-26。基线：`82835a9`。范围为现有应用的布局、视觉与阅读体验，使用原会话、真实任务和已发布产物。

## 设计方向

先提供三版候选供用户比较，用户最终选择手记版。正式界面只保留选定方案，移除预览入口与主题切换。参考 `anthropics/skills` 的 [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)，使用真实内容完成布局，并用浏览器截图检查。

| 项目 | 约定 |
| --- | --- |
| 颜色 | 纸白 `#faf9f6`、墨色 `#262722`、朱红 `#ad352c`、灰线 `#deddd6` |
| 字体 | 中文宋体标题、衬线数字、无衬线正文，使用本机字体栈 |
| 布局 | 桌面结果在左、助手在右；概览与任务置顶，质量、处置和证据依次展开 |
| 层次 | 概览用分隔线，质量用五项对比，助手为持续操作区域；减少大标语与重复装饰 |
| 窄屏 | 内容上下排列，指标重排；宽表格局部滚动，底部提供结果与助手入口 |

## 实施与完成标准

1. 重排页面并整理 CSS，保留会话、提交、报告重试、下载及样例入口；内容导航指向实际区块。已完成。
2. 概览直接从当前报告和任务发布清单生成，不伪造总评分或将配置状态表述为服务在线。无任务、失败与未发布状态清空旧概览。已完成。
3. 改善聊天空态、最新回答起点、发送状态、键盘焦点和长文本阅读。不改变模型、任务、取证协议，不新增依赖或远程资源。已完成。
4. 正式首页验证桌面、平板、手机，核对数据、下载、样例、历史依据、会话清空及失败恢复。交互故障用隔离测试替身。已完成。
5. 保存前后截图与浏览器结果，更新演示说明，按功能分支管理。本轮不重跑 Hadoop，不改历史数据或报告。已完成。
