# 治理方案配置补全

日期：2026-09-29。状态：功能已实现，验证结果见[配置实测](../reports/2026-09-29-治理方案配置实测.md)。

## 问题与目标

迭代一要求允许指定原始版本、清洗规则和评分配置，省略时使用已登记默认方案。原实现只支持启动或 CLI 指定配置文件；网页不能保存、选择方案，Agent 也缺少修改配置的工具。已有快照和版本机制不能替代用户入口。

本次提供两个互通的入口：自然语言描述，以及前端开关、参数表单。用户可保存并选用方案，也可一键将当前草稿保存为共享默认方案。配置动作本身不提交清洗。

## 支持范围

| 类别 | 可配置内容 | 固定边界 |
| --- | --- | --- |
| 清洗规则 | 非典型邮编、标题缺少年份、疑似混合编码的隔离开关；评分事件允许时间上下界 | 开关默认关闭，仅警告；字段、值域、外键、合法候选优先、合法冲突隔离和同值去重仍是固定策略 |
| 评分 | 独立时效参照、窗口、用户/电影/评分三表的正整数相对权重 | 分表五维公式不变；时效仅评分表适用；权重范围 1—1000；空必需表不重新分权 |
| 数据划分 | T1、T2 | UTC，允许下界 ≤ T1 < T2 < 允许上界；仍按条件过滤，不另存分区文件 |

开关开启后会实际隔离记录；主表被隔离还可能连带隔离评分。该策略表示用户选择的质量门槛，不能证明可疑内容事实错误。没有任意脚本、任意公式或推测性填补入口。

## 实施与完成情况

1. **版本和默认登记**：在 catalog 中新增不可变方案表与默认指针。完整内容哈希决定版本，相同内容复用已有方案；改内容产生新版本。默认切换使用 revision 检查，冲突不覆盖，保存并设默认是同一个事务。
2. **自然语言工具**：`governance.configs` 查询，`governance.configure` 修改、保存并可设默认，`governance.set_default` 选择已保存方案。仅用户要求设默认时执行；配置非法会明确拒绝，修正成功前不能回退旧配置提交清洗。
3. **网页入口**：“治理配置”提供开关和表单；“保存并选用”只选择方案；“一键设为默认”直接保存当前草稿。助手旁可选择新任务方案，自然语言保存后同步选择。失败保留草稿，保存成功但列表刷新失败时明确说明已经保存。
4. **任务绑定**：每轮消息开始固定当时的方案。显式选择与消息去重绑定，模型不能用冲突引用覆盖。配置成功后同轮执行采用新方案；进行中的消息、已受理任务和历史报告不跟随默认切换。
5. **执行和回读**：三个开关进入 Streaming 规则，表权重进入正式聚合。任务保存方案引用、名称、完整快照和分项引用；报告与解释按实际参照、权重、开关生成，页面可展开本任务配置。
6. **兼容与检查**：旧默认文件和分项哈希不变。原 `rules-v1`、`metrics-v1` 继续支持；新增 `rules-v2`、`metrics-v2`。CLI `--config` 明确绑定传入文件，不受页面默认切换覆盖。小样本、API、浏览器与真实模型分别记录验证范围。

## 默认行为

首次启动登记配置文件并建立默认；此后以 catalog 中保存的默认为准，重启不恢复初始值。默认对共享服务中的所有会话生效，浏览器为当前会话显式选定的方案优先。下拉框的“默认”表示下一次请求跟随那时的共享默认。

设置默认不更改已发布数据、历史报告、固定交接包或原始配置文件。新方案须重新运行才能产生对应结果，不能只换展示数字。进行中的消息保留开始时的配置，同一请求重传仍返回原记录。

## 验收边界

使用隔离 catalog 和三行工作流样本，不启动真实 Hadoop 或重跑全量。进程内适配器调用实际 Streaming 转换函数，模型替身检查工具协议与界面行为；真实模型检查自然语言到配置、任务快照的路径，两类证据分别列出。新规则尚未产生新的课程全量报告。
