## 重跑入口与边界

普通检查不依赖模型或 Hadoop：

```bash
env -u MOVIELENS_HADOOP_RUNTIME python -m unittest discover -s tests -v
```

隔离浏览器检查，在两个终端分别启动 fixture 与 Playwright；输出目录必须是新目录：

```bash
python scripts/checks/governance_fixture.py --root var/verification/governance-ui --port 8876
```

```bash
NODE_PATH="$PWD/var/browser-check/node_modules" \
  MOVIELENS_GOVERNANCE_FIXTURE=var/verification/governance-ui/fixture.json \
  node scripts/checks/governance_settings_browser.cjs
```

少量真实模型检查，读取已有模型设置，运行数据保存在新的输出目录；不会接触正式任务队列：

```bash
python scripts/checks/governance_model.py --output var/verification/governance-model --provider backup
```

本轮没有启动真实 Hadoop、重跑全量或用新参数覆盖历史指标。Streaming 计算由进程内适配器运行实际转换函数，不能替代新方案的集群资源与全量结果验证。真实模型已验证上述两种表达，不能据此保证所有开放式配置描述都能正确理解；非法或不受支持的参数仍由服务端校验。
